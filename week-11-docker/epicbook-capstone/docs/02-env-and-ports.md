# 02 Environment, ports and persistence

Application: The EpicBook (`github.com/pravinmishraaws/theepicbook`), a Node.js and Express app that renders pages server-side with express-handlebars and talks to MySQL through Sequelize.

## Components found

| Component | Where | Notes |
|---|---|---|
| UI | Handlebars views rendered by Express, static files in `public/assets/` | No separate SPA, no workers |
| API | Express routes `/`, `/cart`, `/gallery`, `/api/cart` | `/health` added by `patches/0001-health-cors-json-logs.patch` |
| Database | MySQL, database `bookstore`, tables Author, Book, Cart, Cartbook, Checkout | Seed SQL in `db/` of the app repo |
| Workers | none | |

## Environment variables

| Variable | Service | Purpose | Source |
|---|---|---|---|
| `NODE_ENV` | backend | selects the `production` block of `config.json` | compose |
| `PORT` | backend | listen port, default 8080 | compose |
| `JAWSDB_URL` | backend | `mysql://epicbook:<DB_PASSWORD>@db:3306/bookstore` | compose, built from `.env` |
| `ALLOWED_ORIGINS` | backend | comma separated CORS allowlist for `/api` | `.env` |
| `MYSQL_ROOT_PASSWORD` | db | root password | `.env`, generated by `scripts/setup.sh` |
| `MYSQL_DATABASE`, `MYSQL_USER`, `MYSQL_PASSWORD` | db | creates `bookstore` and user `epicbook` | compose and `.env` |
| `HTTP_PORT` | proxy | host port published for the proxy, default 80 | `.env` |

`.env` is git-ignored. `.env.example` holds placeholders only. `scripts/setup.sh` generates the two passwords with `openssl rand -hex 16` and sets mode 600.

## Ports

| Port | Service | Exposed to |
|---|---|---|
| 80 | proxy | internet (host port `HTTP_PORT`) |
| 8080 | frontend (runs as uid 101) | front-tier network only |
| 8080 | backend | front-tier network only |
| 3306 | db | back-tier network only (internal, no route outside) |

## Persistence paths

| Path | Holder | What |
|---|---|---|
| `/var/lib/mysql` | named volume `db-data` | database files |
| `/var/log/nginx` | bind mount `./logs/proxy` | proxy access and error logs |
| `./backups` | host directory | `mysqldump` snapshots |
| `/docker-entrypoint-initdb.d` | bind mount `./db-init` (read-only) | schema and seed SQL, runs on first start only |

## Hardening change (Assignment 7)

The frontend image moved to `nginxinc/nginx-unprivileged:1.27-alpine` (user 101, port 8080) after the container audit flagged it as running as root. The proxy upstream and the frontend healthcheck use port 8080.
